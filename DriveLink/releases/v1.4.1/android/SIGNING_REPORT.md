# حالة التوقيع — لا حزم متوفرة

لم يُبنَ أو يُوقّع APK فعلي في البيئة الحالية. لا توجد بصمة أو تجزئة إصدار متحققة. خطوة Release ترفض غياب إعدادات التوقيع، وتتحقق من نجاح `apksigner`، وتطابق بصمة شهادة الـAPK مع `DRIVELINK_SIGNER_SHA256`، وترفض شهادة Android Debug وRelease القابل للتصحيح. يُكتب التقرير الفعلي مع أحجام الملفات ومعرّفاتها ومخرجات أداة التوقيع داخل artifact بعد نجاح التحقق فقط.
